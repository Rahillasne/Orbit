# ORBIT — Open Robot Iteration Toolkit

Interactive demo of ORBIT's dataset readiness analysis, validated benchmark results, and sim-to-real transfer profiling.

**[GitHub](https://github.com/Rahillasne/Orbit)** | **[Blog Post](https://github.com/Rahillasne/Orbit/blob/main/docs/blog-launch.md)**

This Space runs entirely on pre-computed results — no GPU required. It includes:
- **Dataset Readiness Analyzer** — Capability scores, quality breakdown, gap analysis, and prescriptions
- **Validated Results** — Benchmark table with Spearman rho = 0.85, correlation plots
- **Sim-to-Real Transfer** — Distribution gap visualization and transfer readiness scoring

To use ORBIT with your own robot datasets, install from GitHub.
