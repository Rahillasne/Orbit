# ORBIT — Open Robot Iteration Toolkit

Interactive demo of ORBIT's deployment diagnostics and dataset profiling for robot policies.

**[GitHub](https://github.com/Rahillasne/Orbit)** | **[Blog Post](https://github.com/Rahillasne/Orbit/blob/main/docs/blog-launch.md)**

This Space runs on pre-generated synthetic data and includes:
- **Deployment Diagnostics** — Session overview, distribution view, failure analysis, and prescriptions
- **Dataset Profiler** — Coverage maps, capability scores, quality metrics, and data collection prescriptions

To use ORBIT with your own robot deployments, install from GitHub.
